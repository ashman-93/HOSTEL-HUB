📌 About the project
In hostels, the mess cooks for every registered student, even when many are away, which wastes food and makes bills unfair. In laundry often clothes are misplaced, it is receipt based and nobody reports these problems.

**HostelHub** is a C++ console application that:
- lets students **mark mess in/out** in advance,
- gives mess staff an **exact daily headcount** so less food is wasted,
- lets students **book laundry slots** fairly,
- and generates **accurate monthly bills** automatically.

All data is stored in text files, so records are saved between runs.
